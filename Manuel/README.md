# Manuel simEFA

Sources Quarto du manuel d’accompagnement de l’application [simEFA](https://shiny.dcstats.org/simEFA).

## Rendu

Dans un environnement où Quarto est installé :

```bash
quarto render
```

Les formats HTML, PDF et EPUB sont définis dans `_quarto.yml`. Le PDF utilise `cover.tex` et `cover.png`; l’EPUB utilise directement `cover.png`.
